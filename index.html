Sincronização com o GitHub

Grava seus lançamentos num arquivo JSON dentro de um repositório seu, para o mesmo dado aparecer no celular e no PC e nunca se perder. Passo a passo no README.

O token fica salvo apenas neste aparelho (localStorage) e só é enviado para api.github.com.

Backup e planilha

Mesmo com a sincronização, vale guardar uma cópia de vez em quando.
